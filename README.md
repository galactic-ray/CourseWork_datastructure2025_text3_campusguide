# 校园导游咨询系统 - 图形界面版

## 项目简介

这是一个校园导游咨询系统的图形界面版本，基于Qt框架开发。程序提供了友好的图形界面，可以可视化显示校园地图，查询最短路径，以及计算遍历全部景点的最优路径。

【问题描述】
设计有N个校园景点的平面图，为来访客人提供时间最省的优质服务。
【实验要求】
设计校园导游咨询的模拟程序。
（1）采用邻接表或邻接矩阵存储结构。
（2）可以查询任意两个景点间的最短路径。
（3）尝试求解遍历全部景点时间最省的程序。

## 功能特性

1. **图形化显示**：可视化显示校园地图，包括景点和道路
2. **景点管理**：添加、修改景点及其坐标
3. **道路管理**：添加景点之间的道路连接
4. **最短路径查询**：使用Dijkstra算法查询任意两点间的最短路径
5. **TSP遍历**：计算遍历全部景点的最优路径（支持成环和不成环）
6. **数据持久化**：支持CSV格式保存和加载

## 编译要求

- Qt 5.12 或更高版本（或Qt 6）
- C++17 或更高版本的编译器
- qmake 或 CMake

## 编译方法

### 方法1：使用qmake（推荐）

```bash
qmake CampusGuide.pro
make
```

或者使用Qt Creator打开 `CampusGuide.pro` 文件，然后点击"构建"。

### 方法2：使用CMake

```bash
mkdir build
cd build
cmake ..
make
```

## 运行方法

编译完成后，运行生成的可执行文件：

```bash
./CampusGuide
```

或者在Qt Creator中直接点击"运行"。

## 使用说明

1. **加载示例图**：点击"加载示例图"按钮，程序会自动加载一个包含12个景点的示例校园图。

2. **添加景点**：
   - 在"景点操作"区域输入景点名称和坐标（单位：米）
   - 点击"添加景点"按钮

3. **添加道路**：
   - 在"道路操作"区域输入起点和终点的编号
   - 点击"添加道路"按钮
   - 道路距离会根据坐标自动计算

4. **查询最短路径**：
   - 在"最短路径查询"区域输入起点和终点编号
   - 点击"查询最短路径"按钮
   - 最短路径会在图形界面中用红色高亮显示

5. **遍历全部景点**：
   - 在"遍历全部景点"区域输入起点编号
   - 选择是否成环
   - 点击"计算最优遍历"按钮
   - 最优路径会在图形界面中用红色高亮显示

6. **修改景点坐标**：
   - 在"修改景点坐标"区域输入景点编号和新坐标
   - 点击"修改坐标"按钮
   - 相关道路的距离会自动重新计算

7. **保存和加载**：
   - 点击"保存到CSV"可以将当前图形保存到文件
   - 点击"从CSV加载"可以从文件加载图形

8. **交互操作**：
   - 点击图形界面中的景点，可以自动填充相关输入框
   - 点击"清除路径显示"可以清除当前显示的路径

## 文件说明

- `graph.h` / `graph.cpp`：图数据结构和算法实现
- `graphwidget.h` / `graphwidget.cpp`：图形显示组件
- `mainwindow.h` / `mainwindow.cpp`：主窗口和界面逻辑

- `CMakeLists.txt`：CMake构建文件
- `3.cpp`：原始命令行版本（保留作为参考）

## 数据格式

程序使用CSV格式保存数据，文件格式如下：

```
kind,id,name,x,y,u,v
V,0,东门,0.000,0.000,,
V,1,图书馆,60.000,5.000,,
E,,,,,0,1
E,,,,,1,2
...
```

- V行：表示顶点（景点），包含编号、名称、坐标
- E行：表示边（道路），包含起点和终点编号

## 注意事项

- 坐标单位是米
- 道路距离根据坐标自动计算（欧氏距离）
- 程序启动时会自动尝试加载 `graph_xy.csv` 文件
- 如果文件不存在，会尝试加载旧版格式的 `graph.csv` 文件
